# Temperature-Comparison

A C++ program that takes temperature inputs for five days and identifies the day with the highest temperature using Object-Oriented Programming concepts.

Features
- Takes temperature input for five days.
- Stores temperatures using five objects.
- Compares all temperatures.
- Displays the hottest day.

Concepts Used
- Class and Objects
- Member Functions
- Public Data Members
- If-Else Statements
- Comparison Operators

Technologies Used
- Programming Language: C++
- IDE: Visual Studio Code

Project Objective

To understand and practice basic OOP concepts by comparing temperatures of five different days.
